HR Employee Data Analysis Using Databricks SQL

Project Overview

This project focuses on analyzing HR employee data using Databricks SQL. The analysis explores employee information, salary distribution, department-wise employee counts, work experience, and attendance-related data.

Objectives

- Retrieve and analyze employee records.
- Identify employees based on salary and work experience.
- Analyze the number of employees in each department.
- Find the highest-paid employee in each department using window functions.
- Calculate and analyze attendance percentages.
- Identify departments with higher average salaries.
- Filter employees based on their city.

Tools and Technologies

- Platform: Databricks
- Query Language: SQL
- Dataset: HR Employee Dataset

SQL Concepts Used

- SELECT and WHERE clauses
- Filtering conditions
- Aggregate functions such as COUNT() and AVG()
- GROUP BY and HAVING
- Window functions
- Department-wise salary analysis
- City-based filtering
- Data verification using SQL queries

Analysis Performed

1. Retrieved all available employee records.
2. Identified employees earning more than a specified salary.
3. Filtered employees based on work experience and department.
4. Calculated employee counts for each department.
5. Identified the highest-paid employee in each department.
6. Analyzed employee attendance percentages.
7. Compared average salaries across departments.
8. Retrieved employees from Chennai and Coimbatore.
9. Queried employee analysis data to verify the results.

Key Learnings

- Practiced writing SQL queries in Databricks.
- Improved understanding of aggregate and window functions.
- Learned to filter, group, and analyze HR employee data.
- Gained practical experience in extracting insights from structured datasets.

Conclusion

This project demonstrates the use of Databricks SQL to analyze HR employee data and answer business-related questions using SQL queries.
